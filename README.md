# 🌙 Noor

> A beautiful, all-in-one Islamic app designed to make your daily worship simpler, more accessible, and more meaningful.

Noor is a modern Islamic application that brings essential tools for Muslims into one elegant and easy-to-use experience. From prayer times and the Holy Quran to azkar, duas, and Qibla direction, Noor is designed to be a helpful companion throughout your day.

## ✨ Features

| Feature                    | Description                                                                     |
| -------------------------- | ------------------------------------------------------------------------------- |
| 🕌 **Prayer Times**        | View daily prayer times with support for multiple calculation methods.          |
| 📅 **Hijri Date**          | Track the Islamic calendar and view the current Hijri date.                     |
| 📿 **Azkar**               | Access daily azkar and remembrance in an organized interface.                   |
| 📖 **Holy Quran**          | Read the Quran through a clean and comfortable reading experience.              |
| 🤲 **Duaah**               | Browse duas for different occasions and daily needs.                            |
| 🧭 **Qibla Compass**       | Easily find the direction of the Qibla.                                         |
| 🧩 **Multiple Widgets**    | Choose from various widget variants for a personalized experience.              |
| ⚙️ **Calculation Methods** | Select the prayer time calculation method that suits your region or preference. |
| 🎨 **Modern UI**           | Enjoy a beautiful, thoughtful, and responsive design.                           |
| 🚀 **Easy to Use**         | Navigate effortlessly through all the app’s features.                           |

## 🎨 Design Philosophy

Noor is built around a simple idea: **Islamic tools should be beautiful, accessible, and easy to use.**

The app focuses on:

* Clean and modern visual design
* Intuitive navigation
* A calm and comfortable reading experience
* Consistent UI components
* Flexible widgets and personalization
* Accessibility and ease of use

## ⚙️ Prayer Time Calculation

Noor supports multiple prayer time calculation methods, allowing users to select the method most appropriate for their location or preference.

The available methods may include:

* Muslim World League
* Egyptian General Authority of Survey
* University of Islamic Sciences, Karachi
* Umm Al-Qura University, Makkah
* Institute of Geophysics, University of Tehran
* Other supported calculation methods

> The available methods depend on the implementation and prayer time calculation library used by the app.
